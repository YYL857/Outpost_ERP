# Outpost 约仓陪伴扩展

基于原「Noon 自动预约」插件（`content.js` 与原版**逐字节一致**），旁路增加：

- Chrome **Side Panel** 陪伴向导（票号 → 分箱分店 → ASN → 发群文案）
- Noon 页右下角**可拖动悬浮条**（侧栏打开时隐藏）
- `capture-hook.js`：监听预约成功后回填送仓时间（不改抢仓逻辑）
- 默认 API 地址写死为办公室后端：`http://192.168.1.112:8787`（侧栏仍可改）

## 从 ERP 安装 / 更新（推荐）

同事不必等开发者打包发送：

1. Outpost「物流管理」→ **拉取最新 · 约仓陪伴扩展**
2. 解压；首次：Chrome 开发者模式 → 加载已解压 → 选 `asn-booking-extension`
3. **更新**：解压**覆盖**本机原文件夹 → 扩展页点「重新加载」

## 开发者本机加载

1. 确保 API 已启动（默认 `0.0.0.0:8787`）
2. Chrome → 加载已解压 → `apps/asn-booking-extension`
3. 改完代码后点「重新加载」

## 使用

1. 在 Noon 页面点击**浏览器工具栏**上的扩展图标 → 会在**窗口右侧**打开侧栏（不是新标签页）
2. 输入到仓票号对齐 → 按店填 ASN（默认已连 `192.168.1.112:8787`，一般不用改地址）
3. 打开该 ASN 的 schedule 页，在侧栏「约仓监控」里填仓库/日期并「开始监控」
4. 约成后按 **ASN** 把送仓时间记在主机（关侧栏/切页不丢）；侧栏「约仓结果」可核对修改
5. 确认无误后点「回填装箱表」（箱表：ASN + 送仓时间；装箱明细：另把到仓情况改为「已入库」）；也可点「找回约仓」按 ASN 再取一次
6. 「复制文案」发货代群（并附 ASN PDF）

## 同局域网同事

装上本扩展后默认即可连办公室后端。若连不上：确认后端电脑开机、防火墙放行 8787；浏览器试 `http://192.168.1.112:8787/api/ready`。若该电脑 IP 已变，在侧栏改地址并保存（或让维护者改 `api.js` 里的 `DEFAULT_API_BASE` 后重发扩展）。

## 配置

- 店前缀映射：`apps/api/config/shop-prefix-map.json`
- 沙特节假日：`apps/api/config/sa-warehouse-holidays.json`
