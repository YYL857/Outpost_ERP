# Outpost · Listing 对手 PDP 采集扩展

## 默认连办公室后端

扩展默认把数据发到 **`http://192.168.1.112:8787`**（与约仓扩展一致）。

同局域网同事装上后一般**不用改地址**即可采集；你自己电脑若本机也在跑 API，同样走这个局域网 IP。

## 加载方式

1. 确保跑着 Outpost API 的电脑已开机，服务监听 `0.0.0.0:8787`
2. Chrome → 扩展程序 → 开发者模式 → **加载已解压的扩展程序**
3. 选择目录：`apps/listing-extension`
4. 改完代码后务必点「重新加载」

## 使用

1. 打开 Noon 沙特商品详情页（地址含 `saudi-en`）
2. 点扩展图标 →「采集本品页 → Listing」
3. 回到 Outpost「Listing 生成」点「导入扩展采集」

## 同局域网同事

装上本扩展后默认即可连办公室后端。若连不上：

1. 浏览器先打开 `http://192.168.1.112:8787/api/ready` 确认能通
2. 确认后端电脑防火墙放行入站 TCP 8787
3. 若该电脑 IP 已变，在弹窗改地址并保存（或让维护者改 `popup.js` 里的 `DEFAULT_API` 后重发扩展）

以前若在扩展里保存过 `127.0.0.1` / `localhost`，会自动忽略并改用办公室局域网 IP。
