# Outpost · Listing 对手 PDP 采集扩展

从 Noon 商品详情页拉取标题、价格、卖点、描述，写入**当前同事自己的** Listing 对手 inbox，再在网页点「导入扩展采集」。

## 为什么同事电脑以前用不了

1. Listing API 需要登录；扩展直接打 API 会 **401**（约仓扩展有局域网免登，旧版 Listing 扩展没有）。
2. 采集写入按**用户工作区**隔离；未带用户名时会写到管理员目录，同事点「导入扩展采集」是空的。

**0.2.0** 起：局域网可免登写入，但扩展必须填写并保存 **Outpost 登录用户名**。

## 默认连办公室后端

扩展默认 API：`http://192.168.1.112:8787`（与约仓扩展一致）。一般不用改。

## 每位同事安装 / 更新（从 ERP 拉取）

开发者**不必**再打包发给同事。登录 Outpost →「上架文案」→ **拉取最新 · Listing 采集扩展**：

1. 解压 zip 得到 `listing-extension`
2. **首次**：Chrome 开发者模式 → 加载已解压 → 选该文件夹  
   **更新**：解压**覆盖**本机原文件夹 → 扩展页点「重新加载」
3. 扩展图标：填写 **Outpost 用户名** → 保存 → 测试连接
4. Noon 商品页采集 → 网页「导入扩展采集」

开发者本机也可直接加载 `apps/listing-extension`。

## 使用注意

- 须在**单个商品详情页**采集，不要在类目列表页
- 支持 `saudi-en` / `saudi-ar`；页面刷新后再采更稳
- 后端需已更新（含局域网放行 + 按用户名写入）；只更新扩展、旧 API 仍会失败

## 连不上时

1. 浏览器打开 `http://192.168.1.112:8787/api/ready`
2. 确认后端电脑防火墙放行 TCP 8787
3. IP 变了：弹窗改地址并保存
4. 导入仍为空：核对扩展用户名是否与当前网页登录账号一致
